# Task 6: Sales Trend Analysis Using Aggregations
## Objective
Analyze monthly revenue and order volume using SQL aggregation functions.
## Tools Used
- MySQL
## SQL Concepts Used
- GROUP BY
- SUM()
- COUNT(DISTINCT)
- YEAR()
- MONTH()
- ORDER BY
## Outcome
Learned how to analyze sales trends by grouping data by month and year, calculating revenue, and counting orders.
